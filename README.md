# netflix-content-analysis
Interactive Netflix Content Analysis dashboard built with Power BI to explore Movies vs TV Shows, release trends, top countries, and content ratings using data visualization and DAX.
# 🎬 Netflix Content Analysis – Power BI Dashboard

## 📌 Project Overview

Netflix Content Analysis is a data analytics project developed using Microsoft Power BI. This project explores Netflix's Movies and TV Shows dataset to identify content distribution patterns, release trends, country-wise contributions, and content-rating distributions.

The interactive dashboard transforms raw data into meaningful visual insights, making it easier to understand Netflix's content library.

## 🎯 Project Objectives

- Analyze the total number of Netflix titles.
- Compare Movies and TV Shows.
- Explore content release trends over the years.
- Identify the top 10 countries by Netflix title count.
- Analyze content distribution by rating.
- Build an interactive dashboard for data exploration.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated measures and KPIs
- **Netflix Dataset** – Movies and TV Shows data

## 📊 Key Performance Indicators (KPIs)

- Total Titles
- Total Movies
- Total TV Shows

## 📈 Dashboard Visualizations

1. **Movies vs TV Shows:** Compares the distribution of movies and television shows.
2. **Titles by Release Year:** Analyzes Netflix content release trends over time.
3. **Top 10 Countries:** Highlights the countries contributing the most titles.
4. **Content Rating Analysis:** Examines the distribution of titles across different content ratings.
5. **Content Details Table:** Displays title-level information.
6. **Interactive Type Slicer:** Filters the dashboard between Movies and TV Shows.

## 🔍 Key Insights

The dashboard enables users to explore:

- The proportion of movies compared with TV shows.
- Changes in content releases over different years.
- Countries with the highest number of titles.
- The distribution of Netflix titles across content-rating categories.
